# ข้อกำหนดการจัดวางและคืนค่าแผงซ้าย

## 1. เป้าหมายและขอบเขต

ใช้ปุ่ม **จัดเรียงอัตโนมัติ** เพียงตัวเดียว ถอดปุ่ม “จัดเต็มหน้าตามชิ้นที่เลือก” และ “จัดเรียงชิ้นที่มี / ผสมขนาด” ออกจาก DOM และตัวรับเหตุการณ์ โดยคงเครื่องมือเพิ่มชิ้น ทำสำเนา เลือกหลายชิ้น และเลย์เอาต์สลับแถวไว้

การจัดวางเปลี่ยนเฉพาะตำแหน่ง ไม่สร้าง ลบ ย่อ หรือเปลี่ยนดีไซน์ของชิ้นงาน หากต้องการจำนวนเพิ่ม ให้ใช้เพิ่มชิ้นงานหรือทำสำเนาก่อน

## 2. สัญญาพฤติกรรมของค่าตาราง

| ตัวควบคุม       | พฤติกรรม                                                  |
| --------------- | --------------------------------------------------------- |
| คอลัมน์         | จำนวนช่องแนวนอน; 0 ให้คำนวณจากจำนวนชิ้นหรือพื้นที่กระดาษ  |
| แถว             | จำนวนช่องแนวตั้ง; 0 ให้คำนวณจากจำนวนชิ้นหรือพื้นที่กระดาษ |
| ระยะห่างคอลัมน์ | ระยะระหว่างขอบตัดในแนวนอน ตามหน่วยที่เลือก                |
| ระยะห่างแถว     | ระยะระหว่างขอบตัดในแนวตั้ง ตามหน่วยที่เลือก               |

เมื่อแก้คอลัมน์ ระบบเติมจากซ้ายไปขวา เมื่อแก้แถว ระบบเติมจากบนลงล่าง เพื่อให้ค่าที่กำลังปรับมีผลต่อรูปแบบโดยตรง หากระบุทั้งสองค่า จำนวนช่องต้องรองรับชิ้นที่มีครบ ไม่สร้างชิ้นใหม่ในช่องว่าง

ตารางที่มีชิ้นหลายขนาดใช้ขนาดตัดที่ใหญ่ที่สุดเป็นขนาดช่องเพื่อหลีกเลี่ยงการทับกัน ส่วนโหมดอัตโนมัติ 0/0 ยังใช้การเรียงชิ้นหลายขนาดตามพื้นที่จริง โหมดสลับแถวคงอัลกอริทึมเดิมและปิดช่องแถว/คอลัมน์ที่ไม่เกี่ยวข้อง

## 3. การตอบสนองและการบันทึก

- เหตุการณ์ `input` คำนวณและแสดงตำแหน่งภายในเฟรมถัดไปด้วย `requestAnimationFrame` โดยไม่ต้องกดปุ่ม
- เก็บตัวอย่างในสำเนาข้อมูล เพื่อไม่เขียนค่าที่ยังพิมพ์ไม่เสร็จลงโปรเจกต์
- เหตุการณ์ `change` ยืนยันทั้งค่าตารางและตำแหน่งใน transaction เดียว พร้อม autosave
- การยืนยันค่าซ้ำจาก blur ไม่สร้าง Undo ซ้ำ กด Undo ครั้งเดียวคืนทั้งค่าตั้งและตำแหน่งก่อนแก้
- ปุ่มจัดเรียงอัตโนมัติใช้ค่าที่เห็นอยู่ในช่องเดียวกัน ไม่อ่านค่าอีกชุดหนึ่ง
- เปลี่ยนโหมดตาราง/สลับแถวแล้วจัดเรียงทันที

## 4. การตรวจค่าและการกู้คืน

แถว/คอลัมน์รับจำนวนเต็ม 0–1,000 ระยะห่างต้องไม่ติดลบและไม่เกิน 2,000 mm หลังแปลงหน่วย

ถ้าตารางมีช่องไม่ครบ วางเกินพื้นที่ หรือค่าที่กำลังพิมพ์ยังไม่สมบูรณ์ ให้แสดงข้อความภาษาไทยในกลุ่มตารางพร้อม `aria-invalid` และเก็บชิ้นงานกับตำแหน่งที่ยืนยันล่าสุดไว้ ไม่ตัดชิ้นทิ้ง ไม่ย้ายไปหน้าถัดไปเอง และไม่ย่อขนาดจริงเพื่อให้พอดี

ตัวอย่างสำหรับชิ้นขนาดตัด 50 mm จำนวน 6 ชิ้นบน A4: คอลัมน์ 3, แถว 0, ระยะห่าง 2 mm จะจัดเป็น 3 คอลัมน์ × 2 แถว หากต้องการควบคุมแนวตั้ง ให้คืนคอลัมน์เป็น 0 แล้วปรับแถว

## 5. ไอคอนคืนค่าแต่ละช่อง

- ปุ่มเป็นไอคอนรีเซ็ต ไม่มีข้อความบนปุ่ม มี tooltip และ `aria-label` ระบุชื่อค่าที่คืน
- ขนาดเป้าหมาย 32 × 32 px สำหรับเมาส์ และ 44 × 44 px สำหรับอุปกรณ์สัมผัส
- ใช้คีย์บอร์ดเข้าถึงได้ พร้อม hover/focus และปิดปุ่มเมื่อช่องนั้นถูกปิดอยู่
- ค่าเริ่มต้นอิง factory defaults ไม่ใช่ค่าที่ผู้ใช้แก้ล่าสุด
- แถว/คอลัมน์ = 0; ระยะห่าง = 2 mm; กระดาษ = A4; ขอบ = 5 mm; หน่วย = mm; หมายเหตุ = ว่าง
- ขนาดหน้า/ขนาดตัดคืนเป็นคู่ที่สอดคล้องกับประเภท: เข็มกลัด 68/78 mm, แม่เหล็ก 50/50 mm, สติกเกอร์ 40/40 mm เพื่อไม่สร้างค่าหน้าชิ้นงานใหญ่กว่าขนาดตัด
- สีและเส้นคืนตามค่าเริ่มต้นของประเภทเส้นที่กำลังเลือก
- การคืนค่าไม่ลบเทมเพลตที่บันทึกไว้ และไม่เปลี่ยนจำนวนชิ้นงาน

## 6. เกณฑ์ยอมรับ

1. ไม่พบปุ่มเก่าทั้งสองใน DOM และไม่มี handler ที่อ้างถึงปุ่มที่ลบแล้ว
2. แถว คอลัมน์ และช่องว่างที่ถูกต้องเปลี่ยนแคนวาสก่อน blur ได้
3. IDs, ขนาด, ภาพ, ข้อความ และจำนวนชิ้นงานเหมือนเดิมหลังจัดวาง
4. ค่าที่เกินพื้นที่ไม่เปลี่ยนตำแหน่งหรือโปรเจกต์ที่บันทึกไว้
5. ปุ่มคืนค่ากู้จากข้อมูลผิดได้ และยังคง 2 mm จริงแม้ UI แสดง cm/inch
6. Undo หนึ่งครั้งคืนการแก้หนึ่งรอบทั้งหมด
7. แผงซ้ายไม่มี overflow ที่ความกว้าง 390, 768, 1024 และ 1440 px

ตรวจด้วย `npm test` และ `npm run test:layout` พร้อมชุดทดสอบ UI และการส่งออกเดิม
