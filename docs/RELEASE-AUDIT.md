## ไฟล์ที่ตรวจแล้วไม่จำเป็นต้องแก้

- **ซอร์สแอปและชุดทดสอบ:** ทดสอบครบ 8 ชุด ผ่าน 229 จุด ครอบคลุมฟีเจอร์ UI/UX และเลย์เอาต์ล่าสุด การตรวจรอบนี้ไม่พบเหตุให้แก้ logic ของแอป
- **`portable/My-Badge-Studio.html`:** เปรียบเทียบกับผล build จากซอร์สและฟอนต์ปัจจุบันแล้วตรงกันทุก byte จึงไม่สร้างความเปลี่ยนแปลงเทียมให้ไฟล์นี้
- **`package-lock.json`:** ชื่อ รุ่น dependencies และ engines ตรงกับ package.json; เพิ่มเฉพาะ npm scripts จึงไม่ต้องเปลี่ยน lockfile
- **Impeccable skill, ฟอนต์ และใบอนุญาต:** เป็นทรัพยากรประกอบ ไม่ใช่ snapshot หน้าจอ ไม่แก้เนื้อหาต้นฉบับเพียงเพราะ UI เปลี่ยน
- **ไฟล์ตั้งค่าและเอกสารส่วนอื่น:** ตรวจรายชื่อและลิงก์ที่เกี่ยวข้องร่วมกับการรันแอป/ทดสอบ รายการรายไฟล์และ SHA-256 อยู่ใน `release-inventory.json` (ไม่รวมตัว inventory เอง)

ก่อนแก้ดึง commit `2af70b6` จาก main เข้ามาแล้ว เพื่อรักษา README ที่แก้บน GitHub ไว้

## ป้องกันภาพและ HTML เก่ากลับมาอีก

```bash
npm run docs:screenshots  # จับภาพใหม่ด้วย Chromium และข้อมูลตัวอย่าง
npm run verify:release   # ตรวจภาพ/ซอร์ส/HTML portable/ลิงก์/lockfile
npm run test:all          # ตรวจพฤติกรรมแอปทั้งหมด
```

หากเปลี่ยนซอร์สให้สร้าง portable ด้วย `npm run build:portable` และจับภาพใหม่ก่อนตรวจ release รายละเอียดผลทดสอบอยู่ใน [STATUS.md](STATUS.md)

การตรวจและ push repository ไม่ได้ยืนยันการ deploy บนโฮสต์ภายนอกหรือผลพิมพ์จากเครื่องจริง
