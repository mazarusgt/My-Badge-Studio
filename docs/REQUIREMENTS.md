# ขอบเขต My Badge Studio

ยึดข้อแก้ไขล่าสุดของผู้ใช้: เข็มกลัดกลม 44, 57, 58, 59, 68, 73, 75 mm; แม่เหล็กสี่เหลี่ยมจัตุรัส 50, 61, 63.5 mm; สติกเกอร์วงกลม ทุกแบบกำหนดขนาดเองได้ ไม่มีหัวใจ ป้ายชื่อ แม่เหล็กสี่เหลี่ยมผืนผ้า หรือแม่เหล็กภาพถ่าย

## หน่วยและงานพิมพ์

เก็บมิติทุกค่าภายในเป็น mm ไม่แปลงค่าต้นฉบับเมื่อเปลี่ยนหน่วยใน UI ตัวเลือกหน่วย mm/cm/inch ใช้ทั่วแอปและตัวแก้ไขดีไซน์ ส่วนช่องตำแหน่งที่มีตัวเลือกหน่วยเฉพาะยังปรับละเอียดได้ (1 inch = 25.4 mm) เก็บหน้า ขนาดตัด และระยะปลอดภัยแยกกัน ขนาดตัดสำเร็จรูปนอกจาก 57/58/59 mm เป็นค่าเริ่มต้น ต้องปรับให้ตรงแม่พิมพ์ของผู้ใช้ ไม่รับรองว่าขนาดหน้าเท่ากันใช้ขนาดตัดเหมือนกันทุกเครื่อง

ขนาดกระดาษ Letter/A4/A3/A3+ หรือกำหนดเอง แนวตั้ง/แนวนอน ขอบ 4 ด้านแยกกัน ระยะห่างแยกแนว แถว/คอลัมน์อัตโนมัติหรือระบุจำนวน วางผสมขนาดแบบเรียงแถว ไม่อ้างว่าเป็นอัลกอริทึมใช้พื้นที่สูงสุดทางคณิตศาสตร์

หลายหน้า เพิ่ม/สำเนา/ลบ เลย์เอาต์บันทึกตำแหน่ง ขนาด และกระดาษ โหลดลงหน้าปัจจุบันหรือหน้าใหม่ ข้อมูลภาพและข้อความไม่รวมในเลย์เอาต์ ใช้เทมเพลตหรือโปรเจกต์เพื่อเก็บงานออกแบบทั้งหมด

## ออกแบบ

เก็บ PNG/JPEG/WebP ต้นฉบับ เพิ่มหลายรูปและลากวางได้ ไม่ดาวน์โหลดภาพจาก URL ภายนอกเพื่อป้องกันลิงก์เสียและการเปิดเผยข้อมูล ตัดภาพด้วย cover/contain ปรับสเกล ตำแหน่ง และหมุน เพิ่มข้อความหลายเลเยอร์ มีฟอนต์ไทย/ละตินในตัว ปรับสี HEX/RGB ขนาด ตำแหน่ง และหมุนได้ ย้อนกลับ/ทำซ้ำได้ 30 ขั้น

CSV UTF-8 รองรับข้อความในเครื่องหมายคำพูด ตัวแปร {{column}} และคอลัมน์ image ที่อ้างชื่อไฟล์ที่อัปโหลดไว้ สร้างหนึ่งชิ้นต่อแถวบนหน้าใหม่โดยไม่ทับหน้าที่มีอยู่

## เส้นและการส่งออก

สี ความหนา ความทึบ และรูปแบบเส้นแยกสำหรับขอบตัด หน้า พื้นที่ปลอดภัย และมาร์ก แยกแสดงพรีวิวกับส่งออก เครื่องหมายตัดและกากบาทจัดตำแหน่งทั่วไป ไม่อ้างว่าเป็นมาร์กเฉพาะเครื่อง Cricut/Silhouette

PDF หลายหน้าสร้างจาก Chromium แล้วกำหนด MediaBox ตาม mm โดยไม่ย่อสเกลชิ้นงาน SVG ฝังฟอนต์กับภาพต้นฉบับ PNG ระบุ DPI และฝัง pHYs DXF ส่งเฉพาะเส้นตัดหน่วย mm เลือกหน้าปัจจุบัน ทุกหน้า หรือช่วงหน้า SVG/PNG/DXF หลายหน้ารวม ZIP เลือกภาพ/เส้น/มาร์กได้ตามชนิดไฟล์ DXF เป็นเส้นตัดเสมอ

## การบันทึก

บันทึกอัตโนมัติ โปรเจกต์ เทมเพลต และเลย์เอาต์ใน IndexedDB ของเบราว์เซอร์ ดาวน์โหลด/เปิดไฟล์ JSON บัญชีแบบรันบนเซิร์ฟเวอร์เองพร้อม SQLite และ session cookie แยกข้อมูลต่อผู้ใช้ ใช้งานออนไลน์ได้เมื่อ deploy ผ่าน HTTPS พร้อมพื้นที่เก็บข้อมูลถาวร ไม่มีการเชื่อมบริการคลาวด์ภายนอกหรือเรียกเก็บเงินอัตโนมัติ

## พักไว้

AI ทุกชนิด รูปทรงพิเศษ Puzzle QR Code และพอร์ทัลรับงานลูกค้า ไม่รวมในรุ่นนี้

## ข้อจำกัดที่ต้องตรวจนอกระบบ

เครื่องพิมพ์จริงต้องเลือก Actual size/100% และวัดชิ้นทดสอบ เครื่องตัดต้องนำเข้าไฟล์และตั้งค่าตามรุ่น การ deploy ออนไลน์ต้องมีเซิร์ฟเวอร์ โดเมน HTTPS และแผนสำรองฐานข้อมูล ไม่ถือว่าการผ่านทดสอบใน Codex เป็นการเผยแพร่เว็บแล้ว

## พฤติกรรม UI รุ่นปัจจุบัน

- ธีมมืด ภาษาไทย แผงซ้าย/ขวา/บนมีแท็บ ย่อได้ และปรับขนาดตามหน้าจอ
- ลากคลุมหรือ Shift+คลิกเพื่อเลือกหลายชิ้น แก้ภาพ ข้อความ สี และค่าที่รองรับพร้อมกัน
- เมนูลัดบนชิ้นงานมีไอคอนแก้ไข ทำสำเนา และลบ การลบชิ้นงานต้องยืนยันประเภทและจำนวนทุกครั้ง
- แยกตัวแก้ไขดีไซน์จากการจัดหน้า มีเทมเพลต รูป ข้อความ สี/เส้น เลเยอร์ กริด และปุ่มรีเซ็ตภาพแต่ละค่า กดยกเลิกแล้วข้อมูลหลักไม่เปลี่ยน
- มีเครื่องมือจัดเรียงอัตโนมัติตัวเดียว แถว/คอลัมน์/ระยะห่างแสดงผลระหว่างพิมพ์ ยืนยันเมื่อ change และ Undo ได้ในขั้นตอนเดียว ไม่เพิ่ม/ลบ/ย่อชิ้นงานเมื่อจัดเรียง
- ค่าที่ทำให้ตารางไม่พอหรือเกินกระดาษต้องคงตำแหน่งล่าสุดและแสดงข้อผิดพลาด ดู [สัญญาพฤติกรรมการจัดวาง](arrangement-controls-spec.md)
- ไอคอนคืนค่าแต่ละช่องในแผงซ้ายอิง factory defaults และแปลงหน่วยโดยคงมิติจริง
- คำเตือนระยะห่างแสดงค้างเมื่อชิ้นทับ ชิดน้อยกว่า 0.8 mm หรือพื้นที่ชิ้นงานรวมเกิน 82% การตรวจทับใช้รูปทรงจริงและ tolerance 0.001 mm
- คลังเทมเพลตแยกดีไซน์/เลย์เอาต์ สร้าง แก้ไข เปลี่ยนชื่อ/สี ลบได้ และระบุโหมดแก้ไขพร้อมชื่อรายการ
- รูปจากหลายไฟล์วนใช้เฉพาะชิ้นที่เลือกเมื่อมีการเลือกอยู่ ไม่กระจายไปชิ้นที่ไม่ได้เลือก
- ปุ่มใช้ดีไซน์ทั้งหน้ามีสถานะคงอยู่เมื่อดีไซน์ยังตรงกัน และดับเมื่อแก้เฉพาะบางชิ้นจนต่างกัน
