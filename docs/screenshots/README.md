# 🖼️ ภาพหน้าจอจากแอปปัจจุบัน

โฟลเดอร์จริงคือ `docs/screenshots/` ภาพสร้างจากแอปที่รันจริงด้วยโปรเจกต์ตัวอย่าง ไม่ใช้ข้อมูลผู้ใช้และไม่ตกแต่งภาพภายหลัง

| ภาพ                                          | แสดงอะไร                                               | Viewport                |
| -------------------------------------------- | ------------------------------------------------------ | ----------------------- |
| [desktop.png](desktop.png)                   | แคนวาสจัดหน้า ตารางแบบ real-time และปุ่มคืนค่าแผงซ้าย  | 1440 × 1000             |
| [mobile.png](mobile.png)                     | หน้าแอปบนมือถือและแผงที่เรียงอยู่ใต้แคนวาส             | 390 × 844; ถ่ายเต็มหน้า |
| [designer-desktop.png](designer-desktop.png) | ตัวแก้ไขดีไซน์ แถบไอคอน เทมเพลต เลเยอร์ รีเซ็ต และกริด | 1440 × 1000             |
| [designer-mobile.png](designer-mobile.png)   | ตัวแก้ไขดีไซน์บนมือถือ                                 | 390 × 844               |
| [gallery.png](gallery.png)                   | คลังเทมเพลต ปุ่มเพิ่มข้างหัวข้อ และไอคอนแก้ไข/ลบ       | 1440 × 1000             |

## สร้างภาพใหม่

```bash
npm run docs:screenshots
npm run verify:release
```

ต้องมี Chromium (`CHROMIUM_PATH` หรือ `/usr/bin/chromium`) สคริปต์เปิดเซิร์ฟเวอร์ทดสอบที่พอร์ต 5205 และใช้ฐานข้อมูล/โปรไฟล์เบราว์เซอร์ชั่วคราว ปิดและล้างข้อมูลเมื่อจบ

[manifest.json](manifest.json) บันทึกขนาดภาพ เวลา รุ่น Chromium และ SHA-256 ของภาพกับไฟล์ runtime ที่ใช้ถ่าย หากแก้ runtime แล้วไม่ได้ถ่ายภาพใหม่ `verify:release` จะตรวจพบ ภาพจึงไม่ต้องอาศัยวันที่ commit อย่างเดียวในการตัดสินความสดใหม่

`source_commit` คือ commit ฐานขณะถ่าย ภาพและ manifest ถูกบันทึกใน commit ถัดมา ตรวจความตรงกับ runtime ด้วย `source_hashes`
