# สถานะงานและหลักฐานการตรวจสอบ

## ฟังก์ชันที่ทำแล้ว

- ธีมมืด ภาษาไทย ปุ่มมีข้อความ หน้าจอปรับตาม desktop/mobile
- เข็มกลัดกลมรวม 73 mm แม่เหล็กสี่เหลี่ยมจัตุรัส สติกเกอร์วงกลม และขนาดกำหนดเองพร้อมหมายเหตุ/รายละเอียด
- ค่าภายในเป็น mm เลือก mm/cm/inch ทั้งหน่วยหลักและรายช่อง เปลี่ยนหน่วยโดยไม่เปลี่ยนมิติจริง
- กระดาษมาตรฐาน/กำหนดเอง แนวกระดาษ ขอบแยก 4 ด้าน ช่องว่าง แถว/คอลัมน์ และการจัดเรียงแบบผสมขนาด
- หลายหน้า เพิ่ม/สำเนา/ลบ บันทึกและโหลดเลย์เอาต์ลงหน้าปัจจุบันหรือหน้าใหม่
- ภาพต้นฉบับ PNG/JPEG/WebP เลือกหลายไฟล์/ลากวาง ปรับ fit/scale/ตำแหน่ง/หมุน พร้อมประมาณ DPI
- ข้อความหลายเลเยอร์ ฟอนต์ไทย/ละติน สี HEX/RGB ตำแหน่ง ขนาด มุมหมุน และลำดับเลเยอร์
- Undo/redo 30 ขั้น autosave IndexedDB และไฟล์โปรเจกต์ JSON พร้อมเปิดกลับมา
- CSV mail merge พร้อมตัวแปรข้อความและอ้างชื่อไฟล์ภาพ สร้างงานบนหน้าใหม่
- คลังขนาดเริ่มต้น ดีไซน์พร้อมใช้ตามหมวด และเทมเพลตส่วนตัว
- เส้นตัด/หน้า/ปลอดภัย แยกสี ความหนา ความทึบ รูปแบบ พรีวิว/ส่งออก พร้อม crop marks และกากบาททั่วไป
- PDF หลายหน้าพร้อมขนาดกระดาษต่างกัน SVG ฝังต้นฉบับ/ฟอนต์ PNG พร้อม DPI และ DXF เส้นตัด mm เลือกหน้า/ช่วงหน้า และ ZIP เมื่อเหมาะสม
- พิมพ์ตรงหลายหน้า แยก ID ของ SVG แต่ละหน้าเพื่อไม่ให้ภาพหรือ clip ข้ามหน้า
- บัญชีบนเซิร์ฟเวอร์เอง เข้าสู่ระบบ/ออก บันทึก/เปิด/ลบโปรเจกต์ แยกข้อมูลตามบัญชี SQLite และ scrypt

## ผลตรวจในสภาพแวดล้อมนี้

- `npm ci --offline` ติดตั้งซ้ำจาก lockfile สำเร็จ
- `npm test`: **15 ผ่าน, 0 ไม่ผ่าน**
- `npm run test:e2e`: **36 จุดตรวจผ่าน** ด้วย Chromium จริง
- ตรวจ E2E: หน่วยและ 73 mm, ข้อความหลายเลเยอร์, รูปต้นฉบับ 1200×800 px, crop/scale, เลย์เอาต์หน้าใหม่, ผสมขนาด, undo/redo, หลายหน้า, CSV ภาษาไทย, autosave, JSON เปิดกลับมา, ZIP/SVG, PNG, PDF หลายขนาดกระดาษ, DXF และเตรียมพิมพ์หลายหน้า
- ตรวจบัญชี: บันทึก/เปิดงาน, ไม่อนุญาตผู้ไม่เข้าสู่ระบบ, ปฏิเสธคำขอข้าม Origin, ผู้ใช้อื่นอ่านหรือเขียนทับโปรเจกต์ไม่ได้, logout ยกเลิก session
- ตรวจ responsive: viewport 390 px ไม่มีหน้าล้นแนวนอน ไม่มี JavaScript runtime error ในชุดทดสอบ
- PDF MediaBox เท่าขนาดกระดาษที่คำนวณจาก mm และตรวจสี่เหลี่ยม 100×100 mm โดย raster ที่ 254 DPI (10 px/mm) ได้ **1000×1000 px**
- ตรวจ PDF ด้วย pdfimages: ภาพตัวอย่างยังเป็น **1200×800 px** ไม่มีการย่อพิกเซลต้นฉบับระหว่างสร้าง PDF
- ตรวจข้อความไทยใน PDF ด้วย pdftotext อ่านกลับได้
- ตรวจภาพหน้าจอ desktop/mobile และไฟล์ ZIP/PNG ที่สร้างจริง

## ยังไม่ได้ยืนยันนอกเครื่องนี้

- ยังไม่ได้พิมพ์กระดาษจริงหรือวัดจากเครื่องพิมพ์ของผู้ใช้ การทดสอบไฟล์ไม่ทดแทนการตั้งค่า Actual size/100% และการวัดงานจริง
- ยังไม่ได้ทดสอบเครื่องตัดจริง กากบาททั่วไปไม่ใช่ registration marks เฉพาะรุ่น ไม่มีการอ้างว่ารองรับ Print Then Cut ของเครื่องทุกยี่ห้อ
- ซอร์สและ HTML ไฟล์เดียวส่งขึ้น GitHub branch `codex/my-badge-studio` แล้ว ยังไม่ได้ deploy เว็บไซต์ผ่านอินเทอร์เน็ต ตั้งโดเมน/HTTPS หรือทดสอบการสำรอง-กู้คืนบนโฮสต์จริง
- ระบบบัญชีที่ทดสอบคือเซิร์ฟเวอร์ของแอป ไม่ใช่บริการคลาวด์ภายนอก ก่อนเปิดบริการสาธารณะขนาดใหญ่ต้องเตรียม hosting, persistent storage, backups, rate limits และการจัดการบัญชีตามคู่มือ deploy

## ขอบเขตและเพดาน

ไม่รวมรูปทรงพิเศษ แม่เหล็กสี่เหลี่ยมผืนผ้า แม่เหล็กภาพถ่าย AI Puzzle QR Code และพอร์ทัลรับงานตามที่พักไว้ การจัดเรียงผสมขนาดเป็นแบบเรียงแถว ไม่รับรองการใช้พื้นที่สูงสุดทุกกรณี

โปรเจกต์สูงสุด 100 หน้า/10,000 ชิ้น, 1,000 ชิ้นต่อหน้า, 50 MB ต่อคำขอเซิร์ฟเวอร์, ภาพนำเข้าหนึ่งไฟล์ไม่เกิน 25 MB, PNG ไม่เกิน 50 ล้านพิกเซลต่อหน้า, PDF ทีละหนึ่งงาน, 50 โปรเจกต์ต่อบัญชี ข้อจำกัดเหล่านี้แจ้งเมื่อทำรายการที่เกิน ไม่ลดขนาดงานเพื่อให้ผ่าน

## รุ่น HTML ไฟล์เดียว

`portable/My-Badge-Studio.html` รวมโค้ดและฟอนต์ไว้ในไฟล์เดียว ไม่ต้องติดตั้ง Node.js ใช้ PDF ผ่านหน้าต่างพิมพ์ ไม่มีบัญชีเซิร์ฟเวอร์ ชุดทดสอบออฟไลน์ผ่าน 9 จุด (โหลด HTML ไฟล์เดียวผ่านเซิร์ฟเวอร์ทดสอบแล้วปิดเครือข่าย) การเปิด file:// โดยตรงใน Chromium ของสภาพแวดล้อมนี้ถูกนโยบายบล็อก จึงยังต้องตรวจบน Chrome/Edge ของผู้ใช้
