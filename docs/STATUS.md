# ✅ สถานะปัจจุบันและผลตรวจสอบ

ตรวจจากซอร์สและแอปที่รันจริงเมื่อ **14 พฤศจิกายน 2026** รายละเอียดไฟล์ที่เคยล้าสมัยอยู่ใน [รายงานตรวจ repository](RELEASE-AUDIT.md)

## ฟีเจอร์ที่มีอยู่ในรุ่นนี้

- 🌙 ธีมมืด ภาษาไทย แยกแท็บเครื่องมือและปรับขนาดแผงซ้าย/ขวา/บนได้
- 🎯 ลากคลุมหรือ Shift + คลิกเลือกหลายชิ้น แก้คุณสมบัติและใส่ภาพให้ชิ้นที่เลือกพร้อมกัน
- 🛠️ ป๊อปอัปแก้ไข / ทำสำเนา / ลบ พร้อมยืนยันก่อนลบชิ้นงาน
- 🎨 ตัวแก้ไขดีไซน์เฉพาะงาน: เทมเพลต รูปภาพ ข้อความ สีและเส้น เลเยอร์ และกริด พร้อมรีเซ็ตขนาดภาพ/หมุน/X/Y
- 📐 เครื่องมือ **จัดเรียงอัตโนมัติ** แบบตารางหรือสลับแถว แถว/คอลัมน์/ช่องว่างแสดงผลทันที จำนวนและดีไซน์ชิ้นงานคงเดิม และย้อนกลับได้
- ↩️ ไอคอนคืนค่าเริ่มต้นข้างการตั้งค่าแถบซ้าย; 0 แถว/คอลัมน์หมายถึงคำนวณอัตโนมัติ หากพื้นที่ไม่พอจะคงตำแหน่งเดิมพร้อมแจ้งเตือน
- 📏 หน่วยหลัก mm/cm/in ใช้ร่วมกับค่ามิติที่เกี่ยวข้อง โดยไม่เปลี่ยนขนาดจริง
- ⚠️ ตรวจชนตามรูปทรง พร้อมคำเตือนเมื่อซ้อนกันหรือพื้นที่แน่น
- 🗂️ แกลเลอรีดีไซน์และเลย์เอาต์แยกกัน เพิ่ม/แก้ไข/เปลี่ยนชื่อ/สี/ลบ พร้อมแสดงชื่อรายการที่กำลังแก้ไข
- ⌨️ Delete, Ctrl+D, Ctrl+Shift+S/C, Ctrl+Shift+Delete สำหรับลบเฉพาะภาพ และ Ctrl+เลื่อนเมาส์เพื่อซูม
- 💾 หลายหน้า, Undo/Redo, บันทึกในเบราว์เซอร์, ดาวน์โหลด/เปิดโปรเจกต์ JSON, CSV และบัญชีเซิร์ฟเวอร์
- 🖨️ ส่งออก PDF/SVG/PNG/DXF และพิมพ์; รุ่น HTML ไฟล์เดียวรวมฟอนต์ ใช้ PDF ผ่านหน้าต่างพิมพ์และไม่มีบัญชีเซิร์ฟเวอร์

ภาพใหม่ **5 ภาพ** ครอบคลุม desktop, mobile, ตัวแก้ไขดีไซน์ทั้งสองขนาด และแกลเลอรี การจับภาพใช้ข้อมูลตัวอย่าง ตรวจไม่ให้หน้าล้นแนวนอนหรือมี runtime error ดู [ภาพและวิธีสร้างซ้ำ](screenshots/README.md)

## ตรวจความสดของไฟล์ด้วยตนเอง

```bash
npm run test:all
npm run docs:screenshots
npm run verify:release
npm run format:check
```

`verify:release` เปรียบเทียบ HTML portable กับซอร์สปัจจุบัน ตรวจ hash ภาพและซอร์สที่ใช้จับภาพ ตรวจ package lock, โมดูลที่เซิร์ฟเวอร์ให้บริการ และลิงก์เอกสารภายใน repository หากซอร์สเปลี่ยนหลังจับภาพจะตรวจไม่ผ่านจนกว่าจะสร้างภาพใหม่

## ขอบเขตหลักฐาน

- ซอร์สอยู่บน GitHub สาขา `main`; การ push ไม่ได้หมายความว่าโฮสต์เว็บไซต์ deploy แล้ว ดู [คู่มือ deploy](DEPLOYMENT.md)
- รอบนี้ตรวจด้วยเบราว์เซอร์และไฟล์ที่สร้าง ไม่ได้ทดสอบเครื่องพิมพ์หรือเครื่องตัดจริง การพิมพ์ยังต้องเลือก Actual size / 100%
- การทดสอบ portable เปิดผ่านเซิร์ฟเวอร์ทดสอบแล้วปิดเครือข่าย ไม่ใช่หลักฐานว่า file:// ทำงานเหมือนกันในเบราว์เซอร์ทุกตัว
- การจัดเรียงเป็นแบบตาราง/สลับแถว ไม่รับรองการใช้พื้นที่สูงสุดสำหรับทุกชุดขนาด
