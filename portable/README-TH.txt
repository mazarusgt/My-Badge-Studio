🎨 เปิด My Badge Studio แบบไฟล์เดียว

1. ดาวน์โหลด ZIP จาก branch main แล้วแตกไฟล์ก่อน
2. เปิดโฟลเดอร์ portable
3. เปิด My-Badge-Studio.html ด้วย Google Chrome หรือ Microsoft Edge
   ไม่ใช่ index.html ในโฟลเดอร์หลัก และไม่ต้องติดตั้ง Node.js
4. คลิกชิ้นงานแล้วกดดินสอ หรือกด E เพื่อแก้ไขรูป ข้อความ สี และเลเยอร์
5. ใช้ “ดาวน์โหลดโปรเจกต์” เพื่อเก็บ JSON และ “เปิดโปรเจกต์ (.json)” เพื่อแก้ไขต่อ

📐 จัดหน้า
ปรับแถว คอลัมน์ หรือระยะห่างแล้วเห็นตำแหน่งทันที 0 คืออัตโนมัติ
“จัดเรียงอัตโนมัติ” คงจำนวน ขนาด และดีไซน์เดิม ไม่สร้างหรือลบชิ้นงาน
หากพื้นที่ไม่พอ ระบบแจ้งเตือนและคงตำแหน่งที่ยืนยันล่าสุดไว้
ไอคอนรีเซ็ตข้างแต่ละช่องคืนค่าเริ่มต้นตามประเภทการตั้งค่า

📚 เทมเพลต
กด + ในคลังดีไซน์หรือเลย์เอาต์เพื่อเพิ่มรายการ ดินสอสำหรับแก้ไข
ชื่อและสีอยู่ในขั้นตอนแก้ไขเดียวกัน ข้อมูลเก็บในเบราว์เซอร์/อุปกรณ์นี้

🖨️ PDF
เลือกส่งออก PDF เพื่อเปิดหน้าต่างพิมพ์ แล้วเลือก Save as PDF / บันทึกเป็น PDF
พิมพ์ที่ Actual size / 100% ปิด Fit to page และวัดชิ้นทดสอบก่อนผลิตจริง

รุ่นไฟล์เดียวไม่มีบัญชีหรือบันทึกผ่านเซิร์ฟเวอร์
ควรสำรอง JSON ก่อนย้ายไฟล์ เปลี่ยนเบราว์เซอร์ หรือล้างข้อมูลเบราว์เซอร์
ถ้าเห็นโค้ดแทนแอป ให้ตรวจว่าไฟล์ลงท้าย .html ไม่ใช่ .txt

คู่มือฉบับเต็ม: ../README.md
คู่มือแบบย่อ: ../file_README.md
สถานะและข้อจำกัด: ../docs/STATUS.md
สร้าง HTML ใหม่หลังแก้ runtime: npm run build:portable
ตรวจว่า HTML ตรงซอร์ส: npm run check:portable
