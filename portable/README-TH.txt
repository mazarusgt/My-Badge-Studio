วิธีเปิด My Badge Studio บนคอมพิวเตอร์

1. แตกไฟล์ ZIP ที่ดาวน์โหลดมาก่อน
2. เปิดโฟลเดอร์ portable
3. คลิกขวาที่ My-Badge-Studio.html แล้วเลือก Open with / เปิดด้วย Google Chrome หรือ Microsoft Edge
4. ไม่ต้องติดตั้ง Node.js หรือเปิด terminal สำหรับรุ่นไฟล์เดียวนี้
5. บันทึกงานด้วยปุ่มบันทึกไฟล์ จะได้ JSON สำหรับเปิดแก้ไขครั้งต่อไป

PDF: เลือกส่งออก PDF จะเปิดหน้าต่างพิมพ์ ให้เลือก Save as PDF / บันทึกเป็น PDF และตั้งสเกล 100%
บัญชีและบันทึกบนเซิร์ฟเวอร์: ใช้ได้ในรุ่นเต็มที่ต้องรันเซิร์ฟเวอร์เท่านั้น
ถ้าเปิด HTML แล้วเห็นโค้ด ให้ตรวจว่านามสกุลไฟล์เป็น .html ไม่ใช่ .txt แล้วเปิดด้วยเว็บเบราว์เซอร์

ข้อมูล autosave/เลย์เอาต์อาจต่างกันเมื่อเปลี่ยนเบราว์เซอร์หรือย้ายไฟล์ ควรเก็บ JSON สำรองเสมอ
