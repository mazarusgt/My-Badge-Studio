เทมเพลตและดีไซน์

เลือกขนาดเพื่อเริ่มโปรเจกต์ใหม่ หรือเลือกดีไซน์ใช้กับชิ้นงานปัจจุบัน

เทมเพลตส่วนตัว

เพิ่มข้อมูลจาก CSV

ใส่ตัวแปร เช่น {{name}} ในเลเยอร์ข้อความก่อนนำเข้า แต่ละแถวจะสร้างหนึ่งชิ้น และเพิ่มหน้าตามความจำเป็น

คอลัมน์ image ใช้ชื่อไฟล์รูปที่อัปโหลดไว้แล้ว (รวมส่วนขยาย) ไม่มีการดาวน์โหลดภาพจากลิงก์ภายนอก

บัญชีและโปรเจกต์บนเซิร์ฟเวอร์

ข้อมูลอยู่บนเซิร์ฟเวอร์ที่เปิดแอปนี้ การเปิดออนไลน์ต้องใช้ HTTPS และพื้นที่เก็บข้อมูลถาวร ไฟล์ JSON เป็นสำเนาสำรองที่คุณเก็บเองได้

เริ่มใช้งาน

  1. เลือกชนิด ขนาดหน้า และขนาดตัดให้ตรงแม่พิมพ์
  2. เลือกกระดาษและจัดเต็มหน้า หรือเพิ่มชิ้นงานหลายขนาดแล้วจัดเรียง
  3. คลิกแต่ละชิ้นเพื่อใส่รูปและข้อความ เพิ่มข้อความได้หลายเลเยอร์
  4. เพิ่มหน้า บันทึกเลย์เอาต์ หรือใส่ข้อมูล CSV สำหรับงานจำนวนมาก
  5. ตรวจคำเตือน แล้วส่งออกหรือพิมพ์ที่ 100%

โปรเจกต์บันทึกอัตโนมัติในเบราว์เซอร์นี้ ควรดาวน์โหลดไฟล์ JSON สำรองก่อนล้างข้อมูลเบราว์เซอร์
